Blockfield

Fictional test explorer. Every coin, block, address and figure on this site is invented. It exists only to test Launch Claim Checker v2, which reads two block explorers on different domains and records a verdict only when both show the same thing. Nothing here describes a real coin.

Operated by Brilliant Nodes, the same team that operates the other test explorer used in the demo (checker.brilliantnodes.com). Pages are added as the test cases are built.
